# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This portfolio showcases my skills, projects, achievements, certifications, and resume as a BCA student and aspiring Full Stack Developer.

## 📌 About

This portfolio is designed to present my professional profile in a simple, modern, and responsive way. It highlights my educational background, technical skills, projects, achievements, and provides an easy way to connect with me.

## ✨ Features

- Responsive and modern user interface
- Professional landing page
- About Me section
- Technical Skills
- Project Showcase
- Achievements & Certifications
- Resume Download
- Contact Information
- Smooth scrolling navigation
- Mobile-friendly design

- JavaScript
